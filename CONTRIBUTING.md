# Contributing to the CCHS Bootstrap Analysis Tool

This project is internal to WDG Public Health. The following guidelines are intended to help maintain code quality and ensure smooth collaboration among team members.

## How to Contribute
1. **Clone the repository** and create a new branch for your work:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. **Make your changes** in the `cchs/` directory. Follow the existing code structure and style.
3. **Test your changes** locally to ensure they do not break existing functionality.
4. **Commit your changes** with clear, descriptive messages:
   ```bash
   git commit -m "Add feature: short description"
   ```
5. **Push your branch** to the remote repository:
   ```bash
   git push origin feature/your-feature-name
   ```
6. **Open a pull request** for review. Include a summary of your changes and any relevant context.

## Code Style
- Follow PEP8 for Python code.
- Use clear, descriptive variable and function names.
- Add comments and docstrings where helpful.
- Keep code modular and avoid duplicating logic.

## Review Process
- All changes must be reviewed by at least one other team member before merging.
- Address any feedback or requested changes promptly.

## Issues & Suggestions
- Use the issue tracker to report bugs or request enhancements.
- For urgent issues, contact the project lead directly.
